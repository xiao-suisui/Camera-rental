## 1. 项目概述

本项目为 **C2C 模式相机租赁平台**，采用前后端分离架构，基于 Spring Cloud Alibaba 微服务体系构建。

### 1.1 技术栈
- **后端**: Spring Boot 3.2.4, Spring Cloud Alibaba, Nacos, Gateway, Sentinel, Seata, MyBatis-Plus, Redis, MinIO
- **前端**: Vue 3, Element Plus, Vite, Pinia
- **数据库**: MySQL 8.0
- **部署**: Docker, Docker Compose

### 1.2 项目目标
- ✅ 完整业务闭环：设备发布 → 审核 → 下单 → 支付 → 归还 → 评价
- ✅ 三类角色能力：游客、普通用户（出租者+租用者）、管理员
- ✅ 微服务能力可演示：服务注册、配置管理、网关鉴权、分布式事务、流量控制

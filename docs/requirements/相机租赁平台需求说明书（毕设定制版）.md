# 1. 引言

## 1.1 项目背景

随着全民摄影时代的到来，摄影爱好者、高校学生、小型摄影工作室对中高端单反、微单、专业镜头等设备的短期租赁需求持续增长。专业相机设备单价偏高（数千元至数万元），多数用户仅需短期使用（如旅拍、活动拍摄、课程实践），租赁模式具有极高的性价比，已成为此类用户的首选消费方式�?
结合毕业设计需求，为突出微服务、分布式事务等技术亮点，同时保障演示流程完整可控，本项目摒弃传统B2C模式，采用C2C模式开发相机租赁平台，参考闲鱼交互逻辑，让所有注册用户可同时作为出租者与租用者，简化外部依赖（无真实支付、物流、短信服务），聚焦核心业务闭环，适配毕设演示场景，同时体现平台管控能力与技术实现水平�?
## 1.2 项目目的

1. 开发一套C2C模式的轻量化相机租赁平台，覆盖“设备发布→审核→租赁→模拟支付→归还→评价”的完整业务链路，满足毕设演示的完整性需求�?

3. 简化业务逻辑与外部依赖，全程模拟核心流程，无真实资金流转、物流对接、短信验证，降低开发与部署复杂度，适配毕设环境�?
4. 实现优惠券、评价、站内信等基础扩展功能，完善业务闭环，同时保留毕设友好设计（数据可初始化、部署便捷、代码规范），便于答辩演示与评审�?

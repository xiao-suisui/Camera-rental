## 2. 当前进度快照（截至 2026-04-24）

### 2.1 已完成

1. RabbitMQ 基础接入完成：
- 4 个服务 bootstrap 已导入 `rabbitmq-config.yaml`。
- `service/docker-compose.yml` 已新增 RabbitMQ 服务及依赖关系。

2. 订单状态主流程已闭环：
- 已支持 `PAID -> TO_SHIP -> TO_RETURN -> RETURNED/OVERDUE -> FINISHED`。
- 已有“确认收货”动作（接口为 `/order/{orderId}/receive`）。

3. 订单通知主链路已事件化：
- `OrderService` 发货/收货/申请归还/确认归还，均改为 `OrderNotificationProducer` 写 Outbox。
- 取消订单（手动取消 + 超时取消）均发送补偿事件。

4. 同步兜底链路已移除：
- `MessageFeignClient` 已删除，不再保留同步通知回退路径。

5. Outbox 可观测接口已上线：
- 新增 `GET /order/admin/outbox/metrics`。
- 支持 `pendingCount`（NEW）、`failedCount`（FAILED）、`retryCount`（SUM(retry_count)）。

6. 数据库脚本已补齐 MQ 表：
- `sql/schema.sql` 已新增 `mq_outbox`、`mq_consume_log`。

7. 日志一期已落地：
- `operation_log` 表已在 `sql/schema.sql` 中新增。
- `OperationLogAspect` 已实现数据库落库（失败不影响主流程），并保留控制台日志。
- 已提供管理员日志查询接口：`GET /order/admin/operation-logs`。

### 2.2 进行中

1. Seata 残留治理收口（代码与文档一致性）。
2. MQ 拓扑声明收敛与联调（目标 vhost：`/camera-rental`）。
3. 订单与评价查询接口权限收口（防越权）持续推进中。
4. 文档统一治理（主计划已收敛，持续维护）。
5. 环境启动自检脚本推进中：
- 已新增 `service/scripts/check-middleware.ps1`，覆盖 MySQL/Redis/Nacos/RabbitMQ 连通性检查。
6. 关键业务场景补齐已新增一轮落地：
- `order-service` 已补齐 `CouponFeignClient` fallback，避免依赖故障导致下单链路异常中断。
- 下单链路已补充关键边界校验：租期非法（开始晚于结束/结束早于当前）、自租拦截、优惠券状态/门槛校验、Feign 结果判空与错误码判断。

7. 下单链路 L1 集成验证已闭环：

## 7. 风险与策略（更新）

| 风险 | 触发表现 | 预防策略 | 处置策略 |
|---|---|---|---|
| MQ 重复或堆积 | 延迟升高/DLQ 增长 | 幂等键、重试上限、DLQ 监控 | 优先处理 DLQ，必要时暂停有问题消费者 |
| Outbox 堆积 | NEW/FAILED 持续增长 | 发布任务健康检查与阈值告警 | 扩容发布任务并排查 broker/network |
| 功能回归遗漏 | 发布后出现主流程故障 | 发布前最小回归集合强制执行 | 回滚并按场景补测后再发布 |
| 文档漂移 | 新成员误判状态 | 单一主文档 + 索引治理 | 每周同步文档与代码状态 |

## 第一批：P0 后端严重缺陷（5 项）

### 1. 密码明文写入操作日志
- [ ] `OperationLogAspect.java` — 序列化前过滤敏感字段（password/token/secret → `***`）
- [ ] `UserService.java` — changePassword 和 login 的 `@OperationLog` 设 `saveRequestData=false`

### 2. 优惠券从未标记已使用
- [ ] `CouponFeignClient.java` — 新增 `consumeCoupon(couponId, orderId, userId)` Feign 方法
- [ ] `CouponController.java` — 新增 `POST /coupon/consume` 接口
- [ ] `CouponService.java` — 实现 consume 逻辑：校验状态 + 改 USED + 关联 orderId + usedCount++
- [ ] `OrderService.java` — createOrder 中调用 couponFeignClient.consumeCoupon()
- [ ] `OrderCreateL1Test.java` — 补充优惠券消耗的测试用例

### 3. 设备无库存锁定
- [ ] `DeviceFeignClient.java` — 新增 `lockDevice(deviceId)` Feign 方法
- [ ] `DeviceController.java` — 新增 `POST /device/{id}/lock` 接口
- [ ] `DeviceService.java` — 实现 lockDevice：条件更新 `UPDATE device SET status='RENTED' WHERE id=? AND status='ACTIVE'`
- [ ] `OrderService.java` — createOrder 中调用 deviceFeignClient.lockDevice()，失败则拒绝下单
- [ ] `OrderService.java` — cancel/timeout 时通过 MQ/Feign 释放设备（已有补偿路径，需确认）

### 4. WebSocket 允许过期 JWT
- [ ] `JwtService.java` — 新增 `parseTokenStrict(token)` 方法，过期时抛异常
- [ ] `ChatWebSocketHandler.java` — extractUserId 改用 `parseTokenStrict()`

### 5. 设备有活跃订单时可被删除
- [ ] `OrderFeignClient.java`（或复用已有）— 新增 `hasActiveOrders(deviceId)` 查询方法
- [ ] `DeviceService.java` — deleteDevice 前调用检查，有活跃订单则拒绝

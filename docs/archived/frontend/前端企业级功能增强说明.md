# 前端企业级功能增强文档

## 🎯 本次更新内容

### 1. 工具类完善

#### StorageUtil（存储工具类）
**功能**：
- `setLocal()` - 设置localStorage
- `getLocal()` - 获取localStorage
- `removeLocal()` - 删除localStorage
- `clearLocal()` - 清空localStorage
- `setSession()` - 设置sessionStorage
- `getSession()` - 获取sessionStorage

**使用示例**：
```javascript
import StorageUtil from '@/utils/storage'

// 存储对象
StorageUtil.setLocal('user', { name: 'John', age: 30 })

// 获取对象
const user = StorageUtil.getLocal('user')
```

#### DateUtil（日期工具类）
**功能**：
- `formatDate()` - 日期格式化
- `formatDateTime()` - 日期时间格式化
- `fromNow()` - 相对时间
- `diffDays()` - 计算天数差
- `isToday()` - 是否今天
- `isExpired()` - 是否过期

**使用示例**：
```javascript
import { formatDateTime, diffDays } from '@/utils/date'

const dateStr = formatDateTime(new Date())
const days = diffDays('2026-01-01', '2026-01-31')
```

#### FormatUtil（格式化工具类）
**功能**：
- `formatMoney()` - 金额格式化
- `formatPercent()` - 百分比格式化
- `maskPhone()` - 手机号脱敏
- `maskIdCard()` - 身份证脱敏
- `maskBankCard()` - 银行卡脱敏
- `maskEmail()` - 邮箱脱敏
- `formatFileSize()` - 文件大小格式化
- `formatNumber()` - 数字千分位格式化

**使用示例**：
```javascript
import { formatMoney, maskPhone } from '@/utils/format'

const price = formatMoney(1234.567) // "1234.57"
const phone = maskPhone('13800138000') // "138****8000"
```

#### ValidateUtil（验证工具类）
**功能**：
- `validatePhone()` - 手机号验证
- `validateEmail()` - 邮箱验证
- `validatePassword()` - 密码强度验证
- `validateIdCard()` - 身份证验证
- `validateUrl()` - URL验证
- `validateMoney()` - 金额验证

**使用示例**：
```javascript
import { validatePhone } from '@/utils/validate'

const rules = {
  phone: [{ validator: validatePhone, trigger: 'blur' }]
}
```

#### CommonUtil（通用工具类）
**功能**：
- `debounce()` - 防抖函数
- `throttle()` - 节流函数
- `deepClone()` - 深拷贝
- `getQueryString()` - 获取URL参数
- `downloadFile()` - 下载文件
- `copyToClipboard()` - 复制到剪贴板
- `scrollToTop()` - 滚动到顶部

**使用示例**：
```javascript
import { debounce, copyToClipboard } from '@/utils/common'

// 防抖搜索
const handleSearch = debounce((keyword) => {
  // 搜索逻辑
}, 500)

// 复制文本
await copyToClipboard('要复制的内容')
```

```javascript
// 手机号脱敏
const maskPhone = (phone) => {
  if (!phone || phone.length !== 11) return phone
  return phone.substring(0, 3) + '****' + phone.substring(7)
}

// 日期格式化
const formatDate = (date) => {
  return dayjs(date).format('YYYY-MM-DD')
}

// 每个组件都要重复写
```

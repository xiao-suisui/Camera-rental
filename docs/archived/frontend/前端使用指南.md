# Camera Rental 前端使用指南

## 🎉 项目完成

完整的Vue 3前端项目已创建完成，包含以下功能：

### ✅ 已完成页面

1. **首页 (Home.vue)**
   - Hero横幅展示
   - 特色服务介绍
   - 热门设备展示

2. **用户认证**
   - 登录页面 (Login.vue)
   - 注册页面 (Register.vue)

3. **设备管理**
   - 设备列表 (DeviceList.vue) - 搜索、筛选、分页
   - 设备详情 (DeviceDetail.vue) - 图片轮播、租赁
   - 发布设备 (DevicePublish.vue) - 表单提交

4. **订单管理**
   - 订单列表 (OrderList.vue) - 查看、支付

5. **优惠券**
   - 优惠券列表 (CouponList.vue) - 可用/已用

6. **个人中心**
   - 用户信息 (UserProfile.vue)

7. **布局组件**
   - 主布局 (MainLayout.vue) - 顶部导航、底部

### 📦 技术栈

- Vue 3.3 (Composition API)
- Vite 4.4
- Vue Router 4.2
- Pinia 2.1 (状态管理)
- Element Plus 2.4 (UI组件库)
- Axios 1.5 (HTTP客户端)

## 🚀 快速开始

### 1. 安装依赖

```bash
cd frontend
npm install
```

### 2. 启动开发服务器

```bash
npm run dev
```

访问：http://localhost:3000

### 3. 构建生产版本

```bash
npm run build
```

## 🔧 配置说明

### API代理配置

在 `vite.config.js` 中配置API代理：

```javascript
server: {
  proxy: {
    '/api': {
      target: 'http://localhost:8080',  // Gateway地址
      changeOrigin: true,
      rewrite: (path) => path.replace(/^\/api/, '')
    }
  }
}
```

### 路由守卫

需要登录的页面会自动跳转到登录页：
- /publish（发布设备）
- /orders（订单列表）
- /coupons（优惠券）
- /profile（个人中心）

## 🐛 常见问题

### 1. API请求失败
- 检查后端服务是否启动
- 检查Gateway端口（8080）
- 查看浏览器Console

### 2. Token验证失败
- 检查Token是否过期
- 重新登录获取新Token
- 检查Gateway JWT配置

### 3. 页面空白
- 检查路由配置
- 查看浏览器Console错误
- 检查组件import路径

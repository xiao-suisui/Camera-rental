# 中间件配置指南

> 本文档说明项目所依赖的各中间件的关键配置、调优参数和运维要点。

---

## 1. Nacos（注册中心 + 配置中心）

### 1.1 基本信息

| 项目 | 值 |
|------|-----|
| 版本 | 2.2+ |
| 默认地址 | http://localhost:8848/nacos |
| 默认账号 | nacos / nacos |
| 本项目使用 | 服务注册发现 + 远端配置管理 |

### 1.2 命名空间

本项目使用自定义命名空间（非 public），ID 配置在各服务 `bootstrap.yml` 中：

```yaml
spring.cloud.nacos:
  config:
    namespace: ${NACOS_NAMESPACE:b87db654-8323-4c9f-ba55-66ce6d0622be}
  discovery:
    namespace: ${NACOS_NAMESPACE:b87db654-8323-4c9f-ba55-66ce6d0622be}
```

> 首次部署时需在 Nacos 控制台创建此命名空间，或修改为自己的命名空间 ID。

### 1.3 配置文件分组策略

| 分组 | 内容 | 说明 |
|------|------|------|
| `DEFAULT_GROUP` | 各服务独立配置 | gateway.yaml, user-service.yaml 等 |
| `SHARED_GROUP` | 共享配置 | datasource, redis, minio, common, cipher |

### 1.4 共享配置列表

每个服务的 `bootstrap.yml` 中引用这些共享配置：

```yaml
shared-configs:
  - data-id: common-config.yaml      # 日志、Jackson、Actuator
    group: SHARED_GROUP
    refresh: true
  - data-id: secret-config.yaml      # 密码/密钥（敏感）
    group: SHARED_GROUP
    refresh: true
  - data-id: datasource-config.yaml  # MySQL + Druid
    group: SHARED_GROUP
    refresh: true
  - data-id: redis-config.yaml       # Redis 连接
    group: SHARED_GROUP
    refresh: true
  - data-id: minio-config.yaml       # MinIO 连接
    group: SHARED_GROUP
    refresh: true
```

### 1.5 敏感配置管理

`secret-config.yaml` 存放所有密码和密钥：

```yaml
DATASOURCE_PASSWORD: xxx
JWT_SECRET: xxx
MINIO_ACCESS_KEY: xxx
MINIO_SECRET_KEY: xxx
REDIS_PASSWORD: xxx
DRUID_PASSWORD: xxx
```

- **不入 Git**（`.gitignore` 中排除）
- 仓库提供 `.example` 模板
- 其他配置文件通过 `${VARIABLE}` 引用这些值

### 1.6 导入配置步骤

1. 登录 Nacos 控制台
2. 切换到正确的命名空间
3. **DEFAULT_GROUP**：逐个导入 `nacos_config/DEFAULT_GROUP/` 下的 5 个 yaml
4. **SHARED_GROUP**：逐个导入 `nacos_config/SHARED_GROUP/` 下的配置
5. 复制 `secret-config.yaml.example` → 填入真实密码 → 导入到 `SHARED_GROUP`

## 2. MySQL

### 2.1 基本信息

| 项目 | 值 |
|------|-----|
| 版本 | 8.0+ |
| 数据库名 | camera_rental |
| 字符集 | utf8mb4 + utf8mb4_unicode_ci |
| 引擎 | InnoDB |

### 2.2 Druid 连接池配置

配置位置：`nacos_config/SHARED_GROUP/datasource-config.yaml`

```yaml
spring.datasource.druid:
  initial-size: 5          # 初始连接数
  min-idle: 5              # 最小空闲连接
  max-active: 20           # 最大活跃连接
  max-wait: 60000          # 获取连接最大等待时间（ms）
  time-between-eviction-runs-millis: 60000   # 空闲检测间隔
  min-evictable-idle-time-millis: 300000     # 最小空闲存活时间（5分钟）
  validation-query: SELECT 1                  # 心跳检测 SQL
  test-while-idle: true                       # 空闲时检测
  test-on-borrow: false                       # 获取时不检测（性能考虑）
  test-on-return: false                       # 归还时不检测
  pool-prepared-statements: true              # 启用 PSCache
  filters: stat,wall                          # SQL 统计 + SQL 防火墙
```

### 2.3 Druid 监控面板

配置位置：`datasource-config.yaml`

```yaml
stat-view-servlet:
  enabled: ${DRUID_STAT_VIEW_ENABLED:false}
  url-pattern: /druid/*
  reset-enable: false
  login-username: ${DRUID_USERNAME:root}
  login-password: ${DRUID_PASSWORD:change-me}
  allow: ${DRUID_ALLOW_IP:127.0.0.1}
```

默认策略：Druid 面板关闭，仅在维护窗口临时开启，并限制内网/IP 白名单访问。

维护开窗后，可通过 Gateway 路由访问各服务的 Druid 面板：

| 服务 | 访问地址 |
|------|---------|
| User Service | http://localhost:8080/user/druid |
| Device Service | http://localhost:8080/device/druid |
| Order Service | http://localhost:8080/order/druid |
| Coupon Service | http://localhost:8080/coupon/druid |

> 维护完成后应立即恢复：`DRUID_STAT_VIEW_ENABLED=false`、`DRUID_WEB_STAT_ENABLED=false`。

### 2.4 慢 SQL 监控

```yaml
connection-properties:
  druid.stat.mergeSql: true         # 合并相同结构的 SQL
  druid.stat.slowSqlMillis: 5000    # 慢 SQL 阈值 5 秒
```

## 3. Redis

### 3.1 基本信息

| 项目 | 值 |
|------|-----|
| 版本 | 7.x |
| 客户端 | Lettuce（Spring Boot 默认） |
| 默认端口 | 6379 |

### 3.2 连接配置

配置位置：`nacos_config/SHARED_GROUP/redis-config.yaml`

```yaml
spring.data.redis:
  host: ${REDIS_HOST:localhost}
  port: ${REDIS_PORT:6379}
  password: ${REDIS_PASSWORD:}
  database: 0
  timeout: 3000
  lettuce.pool:
    max-active: 8
    max-idle: 8
    min-idle: 0
    max-wait: -1ms    # 无限等待
```

### 3.3 用途总览

| 功能 | Key 前缀 | 说明 |
|------|---------|------|
| 业务缓存 | `camera-rental:{domain}:` | 设备/用户/优惠券 Spring Cache |
| 优惠券库存 | `camera-rental:coupon:stock:{id}` | 原子扣减防超发 |
| 防重复提交 | `camera-rental:repeat:` | SETNX 分布式锁 |

### 3.4 缓存 TTL 策略

| 缓存域 | TTL | 说明 |
|--------|-----|------|
| device | 30 min | 设备详情 |
| deviceSearch | 10 min | 搜索结果（更新频繁） |
| user | 60 min | 用户信息 |
| coupon | 15 min | 优惠券信息 |
| unreadCount | 5 min | 未读消息数（高频查询） |

配置位置：`RedisConfig.java` → `cacheManager()` 方法。

### 3.5 序列化方式

| 部分 | 序列化器 |
|------|---------|
| Key | `StringRedisSerializer` |
| Value | `GenericJackson2JsonRedisSerializer` |
| Hash Key | `StringRedisSerializer` |
| Hash Value | `GenericJackson2JsonRedisSerializer` |

## 4. MinIO（对象存储）

### 4.1 基本信息

| 项目 | 值 |
|------|-----|
| 协议 | S3 兼容 |
| API 端口 | 9000 |
| Console 端口 | 9001 |
| Bucket | camera-rental |

### 4.2 连接配置

配置位置：`nacos_config/SHARED_GROUP/minio-config.yaml`

```yaml
minio:
  endpoint: ${MINIO_ENDPOINT}
  access-key: ${MINIO_ACCESS_KEY}
  secret-key: ${MINIO_SECRET_KEY}
  bucket-name: camera-rental
  connect-timeout: 10000
  write-timeout: 60000
  read-timeout: 60000
```

### 4.3 Bucket 策略

Bucket 应设置为 **公开读**（public-read），允许匿名 GET 请求。上传后返回永久公开链接：

```
{endpoint}/{bucket-name}/{fileName}
```

### 4.4 文件管理

| 操作 | 方法 |
|------|------|
| 上传 | `MinioService.uploadFile(MultipartFile)` → 返回公开 URL |
| 删除 | `MinioService.deleteFile(fileName)` |
| 访问 | 直接通过公开 URL 访问 |

文件命名策略：UUID + 原始扩展名（如 `a1b2c3d4.jpg`），避免冲突。

### 4.5 条件加载

MinIO 相关 Bean 使用 `@ConditionalOnClass(MinioClient.class)` / `@ConditionalOnBean(MinioClient.class)` 注解，未配置 MinIO 依赖的服务（如 Gateway）不会加载。

## 5. Sentinel（流控 + 熔断）

### 5.1 基本信息

| 项目 | 值 |
|------|-----|
| Dashboard 端口 | 8858 |
| 各服务通信端口 | 8719-8723（每个服务不同） |
| 启用方式 | `eager: true`（主动连接 Dashboard） |

### 5.2 各服务 Sentinel 端口

| 服务 | Sentinel 端口 |
|------|--------------|
| User Service | 8719 |
| Gateway | 8720 |
| Device Service | 8721 |
| Order Service | 8722 |
| Coupon Service | 8723 |

### 5.3 网关流控

配置位置：`camera-rental-gateway.yaml`

```yaml
spring.cloud.sentinel:
  transport:
    dashboard: ${SENTINEL_DASHBOARD:localhost:8858}
    port: 8720
  eager: true
  scg:
    fallback:
      mode: response
      response-body: '{"code":503,"message":"服务繁忙，请稍后再试"}'
```

在 Sentinel Dashboard 中可动态配置：

- **流控规则**：对 Gateway 路由设置 QPS 上限
- **降级规则**：响应时间超阈值自动熔断
- **热点规则**：针对热点参数限流

### 5.4 Feign 调用降级

配置位置：`camera-rental-order-service.yaml`

```yaml
feign:
  sentinel:
    enabled: true    # 启用 Sentinel 对 Feign 的整合
```

当下游服务不可用时，自动触发 Fallback 类返回降级响应。

## 6. Knife4j / OpenAPI（API 文档）

### 6.1 各服务配置

每个业务服务在 Nacos 配置中启用 OpenAPI：

```yaml
springdoc:
  api-docs:
    enabled: true
  packages-to-scan: com.example.camerarental.{service}.controller
```

### 6.2 网关聚合

配置位置：`camera-rental-gateway.yaml`

```yaml
knife4j:
  gateway:
    enabled: true
    strategy: manual
    routes:
      - name: 用户服务
        service-name: camera-rental-user-service
        url: /user/v3/api-docs
        order: 1
      - name: 设备服务
        service-name: camera-rental-device-service
        url: /device/v3/api-docs
        order: 2
      - name: 订单服务
        service-name: camera-rental-order-service
        url: /order/v3/api-docs
        order: 3
      - name: 优惠券服务
        service-name: camera-rental-coupon-service
        url: /coupon/v3/api-docs
        order: 4
```

### 6.3 访问方式

| 入口 | 地址 |
|------|------|
| Knife4j UI | http://localhost:8080/doc.html |
| Swagger UI | http://localhost:8080/swagger-ui.html |
| OpenAPI JSON | http://localhost:8080/{service}/v3/api-docs |

## 8. 日志配置

### 8.1 通用日志配置

配置位置：`nacos_config/SHARED_GROUP/common-config.yaml`

```yaml
logging:
  level:
    root: INFO
    org.springframework: INFO
    com.alibaba.nacos: WARN
  file:
    path: ${LOG_PATH:/var/logs/camera-rental}
  logback:
    rollingpolicy:
      max-file-size: 100MB    # 单文件上限
      max-history: 30          # 保留天数
```

### 8.2 各服务日志级别

各服务在自己的 Nacos 配置中可覆盖日志级别：

```yaml
logging:
  level:
    com.example.camerarental: warn    # 业务日志
    com.baomidou.mybatisplus: warn    # MyBatis-Plus
```

开发环境可改为 `debug` 以查看 SQL 和详细日志。

### 8.3 Actuator 端点

```yaml
management:
  endpoints:
    web:
      exposure:
        include: health,info,metrics
  endpoint:
    health:
      show-details: when-authorized
```

健康检查地址：`GET /actuator/health`

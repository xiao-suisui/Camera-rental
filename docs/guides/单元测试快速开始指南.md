# 🚀 快速开始：单元测试实施指南

## 📋 第一步：添加测试依赖

### 1. 在父POM中添加测试依赖管理

打开 `service/pom.xml`，在 `<dependencyManagement>` 中添加:

```xml
<!-- Mockito -->
<dependency>
    <groupId>org.mockito</groupId>
    <artifactId>mockito-core</artifactId>
    <version>5.11.0</version>
    <scope>test</scope>
</dependency>

<!-- Mockito JUnit Jupiter -->
<dependency>
    <groupId>org.mockito</groupId>
    <artifactId>mockito-junit-jupiter</artifactId>
    <version>5.11.0</version>
    <scope>test</scope>
</dependency>

<!-- H2 Database (用于测试) -->
<dependency>
    <groupId>com.h2database</groupId>
    <artifactId>h2</artifactId>
    <version>2.2.224</version>
    <scope>test</scope>
</dependency>
```

### 2. 在各个微服务POM中添加测试依赖

打开各个服务的 `pom.xml` (user-service, device-service等)，在 `<dependencies>` 中添加:

```xml
<!-- Spring Boot Test -->
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-test</artifactId>
    <scope>test</scope>
    <exclusions>
        <exclusion>
            <groupId>org.junit.vintage</groupId>
            <artifactId>junit-vintage-engine</artifactId>
        </exclusion>
    </exclusions>
</dependency>

<!-- Mockito -->
<dependency>
    <groupId>org.mockito</groupId>
    <artifactId>mockito-core</artifactId>
    <scope>test</scope>
</dependency>

<dependency>
    <groupId>org.mockito</groupId>
    <artifactId>mockito-junit-jupiter</artifactId>
    <scope>test</scope>
</dependency>

<!-- H2 Database -->
<dependency>
    <groupId>com.h2database</groupId>
    <artifactId>h2</artifactId>
    <scope>test</scope>
</dependency>
```

## 🧪 第三步：编写测试用例

### 1. 工具类测试示例

创建: `camera-rental-common/src/test/java/com/example/camerarental/common/utils/ValidationUtilsTest.java`

```java
package com.example.camerarental.common.utils;

import org.junit.jupiter.api.DisplayName;
import org.junit.jupiter.api.Test;

import static org.junit.jupiter.api.Assertions.*;

@DisplayName("ValidationUtils 工具类测试")
class ValidationUtilsTest {

    @Test
    @DisplayName("测试有效手机号验证")
    void testValidPhone() {
        assertTrue(ValidationUtils.isValidPhone("13800138000"));
        assertTrue(ValidationUtils.isValidPhone("15912345678"));
        assertTrue(ValidationUtils.isValidPhone("18600000000"));
    }

    @Test
    @DisplayName("测试无效手机号验证")
    void testInvalidPhone() {
        assertFalse(ValidationUtils.isValidPhone(null));
        assertFalse(ValidationUtils.isValidPhone(""));
        assertFalse(ValidationUtils.isValidPhone("1234567890"));
        assertFalse(ValidationUtils.isValidPhone("28012345678"));
        assertFalse(ValidationUtils.isValidPhone("138001380001")); // 太长
    }

    @Test
    @DisplayName("测试强密码验证")
    void testStrongPassword() {
        assertTrue(ValidationUtils.isStrongPassword("abc123456"));
        assertTrue(ValidationUtils.isStrongPassword("Test1234"));
        assertTrue(ValidationUtils.isStrongPassword("MyPass123"));
    }

    @Test
    @DisplayName("测试弱密码验证")
    void testWeakPassword() {
        assertFalse(ValidationUtils.isStrongPassword(null));
        assertFalse(ValidationUtils.isStrongPassword("abc")); // 太短
        assertFalse(ValidationUtils.isStrongPassword("12345678")); // 只有数字
        assertFalse(ValidationUtils.isStrongPassword("abcdefgh")); // 只有字母
    }

    @Test
    @DisplayName("测试手机号脱敏")
    void testMaskPhone() {
        assertEquals("138****8000", ValidationUtils.maskPhone("13800138000"));
        assertEquals("159****5678", ValidationUtils.maskPhone("15912345678"));
        assertNull(ValidationUtils.maskPhone(null));
        assertEquals("", ValidationUtils.maskPhone(""));
    }
}
```

### 2. Service层测试示例

创建: `camera-rental-user-service/src/test/java/com/example/camerarental/user/service/UserServiceTest.java`

```java
package com.example.camerarental.user.service;

import com.example.camerarental.common.exception.BusinessException;
import com.example.camerarental.user.dto.LoginRequest;
import com.example.camerarental.user.dto.LoginResponse;
import com.example.camerarental.user.dto.RegisterRequest;
import com.example.camerarental.user.entity.User;
import com.example.camerarental.user.mapper.UserMapper;
import org.junit.jupiter.api.BeforeEach;
import org.junit.jupiter.api.DisplayName;
import org.junit.jupiter.api.Test;
import org.junit.jupiter.api.extension.ExtendWith;
import org.mockito.InjectMocks;
import org.mockito.Mock;
import org.mockito.junit.jupiter.MockitoExtension;
import org.springframework.security.crypto.bcrypt.BCryptPasswordEncoder;

import static org.junit.jupiter.api.Assertions.*;
import static org.mockito.ArgumentMatchers.any;
import static org.mockito.ArgumentMatchers.eq;
import static org.mockito.Mockito.*;

@ExtendWith(MockitoExtension.class)
@DisplayName("UserService 单元测试")
class UserServiceTest {

    @Mock
    private UserMapper userMapper;

    @Mock
    private BCryptPasswordEncoder passwordEncoder;

    @InjectMocks
    private UserService userService;

    private User mockUser;

    @BeforeEach
    void setUp() {
        mockUser = User.builder()
                .id(1L)
                .phone("13800138000")
                .password("$2a$10$encodedPassword")
                .nickname("测试用户")
                .role("USER")
                .status("ACTIVE")
                .build();
    }

    @Test
    @DisplayName("注册成功 - 手机号未注册")
    void testRegisterSuccess() {
        // Given
        RegisterRequest request = new RegisterRequest();
        request.setPhone("13800138000");
        request.setPassword("test123456");
        request.setNickname("新用户");

        when(userMapper.selectByPhone(eq("13800138000"))).thenReturn(null);
        when(passwordEncoder.encode(eq("test123456"))).thenReturn("$2a$10$encodedPassword");
        when(userMapper.insert(any(User.class))).thenReturn(1);

        // When
        assertDoesNotThrow(() -> userService.register(request));

        // Then
        verify(userMapper, times(1)).selectByPhone(eq("13800138000"));
        verify(passwordEncoder, times(1)).encode(eq("test123456"));
        verify(userMapper, times(1)).insert(any(User.class));
    }

    @Test
    @DisplayName("注册失败 - 手机号已注册")
    void testRegisterFailPhoneExists() {
        // Given
        RegisterRequest request = new RegisterRequest();
        request.setPhone("13800138000");
        request.setPassword("test123456");

        when(userMapper.selectByPhone(eq("13800138000"))).thenReturn(mockUser);

        // When & Then
        BusinessException exception = assertThrows(
                BusinessException.class,
                () -> userService.register(request)
        );

        assertEquals(2002, exception.getCode());
        assertTrue(exception.getMessage().contains("已注册"));
        verify(userMapper, times(1)).selectByPhone(eq("13800138000"));
        verify(userMapper, never()).insert(any(User.class));
    }

    @Test
    @DisplayName("登录成功 - 密码正确")
    void testLoginSuccess() {
        // Given
        LoginRequest request = new LoginRequest();
        request.setPhone("13800138000");
        request.setPassword("test123456");

        when(userMapper.selectByPhone(eq("13800138000"))).thenReturn(mockUser);
        when(passwordEncoder.matches(eq("test123456"), eq("$2a$10$encodedPassword")))
                .thenReturn(true);

        // When
        LoginResponse response = userService.login(request);

        // Then
        assertNotNull(response);
        assertNotNull(response.getToken());
        assertEquals(1L, response.getUserId());
        assertEquals("测试用户", response.getNickname());
        verify(userMapper, times(1)).selectByPhone(eq("13800138000"));
        verify(passwordEncoder, times(1)).matches(any(), any());
    }

    @Test
    @DisplayName("登录失败 - 用户不存在")
    void testLoginFailUserNotFound() {
        // Given
        LoginRequest request = new LoginRequest();
        request.setPhone("13800138000");
        request.setPassword("test123456");

        when(userMapper.selectByPhone(eq("13800138000"))).thenReturn(null);

        // When & Then
        BusinessException exception = assertThrows(
                BusinessException.class,
                () -> userService.login(request)
        );

        assertTrue(exception.getMessage().contains("不存在"));
        verify(userMapper, times(1)).selectByPhone(eq("13800138000"));
        verify(passwordEncoder, never()).matches(any(), any());
    }

    @Test
    @DisplayName("登录失败 - 密码错误")
    void testLoginFailWrongPassword() {
        // Given
        LoginRequest request = new LoginRequest();
        request.setPhone("13800138000");
        request.setPassword("wrongpassword");

        when(userMapper.selectByPhone(eq("13800138000"))).thenReturn(mockUser);
        when(passwordEncoder.matches(eq("wrongpassword"), eq("$2a$10$encodedPassword")))
                .thenReturn(false);

        // When & Then
        BusinessException exception = assertThrows(
                BusinessException.class,
                () -> userService.login(request)
        );

        assertTrue(exception.getMessage().contains("密码错误"));
        verify(passwordEncoder, times(1)).matches(any(), any());
    }

    @Test
    @DisplayName("根据ID获取用户 - 成功")
    void testGetUserByIdSuccess() {
        // Given
        when(userMapper.selectById(eq(1L))).thenReturn(mockUser);

        // When
        User user = userService.getById(1L);

        // Then
        assertNotNull(user);
        assertEquals("13800138000", user.getPhone());
        assertEquals("测试用户", user.getNickname());
        verify(userMapper, times(1)).selectById(eq(1L));
    }

    @Test
    @DisplayName("根据ID获取用户 - 用户不存在")
    void testGetUserByIdNotFound() {
        // Given
        when(userMapper.selectById(eq(999L))).thenReturn(null);

        // When & Then
        BusinessException exception = assertThrows(
                BusinessException.class,
                () -> userService.getById(999L)
        );

        assertTrue(exception.getMessage().contains("不存在"));
        verify(userMapper, times(1)).selectById(eq(999L));
    }
}
```

### 3. Controller集成测试示例

创建: `camera-rental-user-service/src/test/java/com/example/camerarental/user/controller/UserControllerIntegrationTest.java`

```java
package com.example.camerarental.user.controller;

import com.example.camerarental.user.dto.LoginRequest;
import com.example.camerarental.user.dto.RegisterRequest;
import com.fasterxml.jackson.databind.ObjectMapper;
import org.junit.jupiter.api.DisplayName;
import org.junit.jupiter.api.Test;
import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.boot.test.autoconfigure.web.servlet.AutoConfigureMockMvc;
import org.springframework.boot.test.context.SpringBootTest;
import org.springframework.http.MediaType;
import org.springframework.test.context.ActiveProfiles;
import org.springframework.test.web.servlet.MockMvc;
import org.springframework.transaction.annotation.Transactional;

import static org.springframework.test.web.servlet.request.MockMvcRequestBuilders.post;
import static org.springframework.test.web.servlet.result.MockMvcResultMatchers.*;

@SpringBootTest
@AutoConfigureMockMvc
@ActiveProfiles("test")
@Transactional
@DisplayName("UserController 集成测试")
class UserControllerIntegrationTest {

    @Autowired
    private MockMvc mockMvc;

    @Autowired
    private ObjectMapper objectMapper;

    @Test
    @DisplayName("注册接口 - 成功")
    void testRegisterSuccess() throws Exception {
        RegisterRequest request = new RegisterRequest();
        request.setPhone("13900139000");
        request.setPassword("test123456");
        request.setNickname("集成测试用户");

        mockMvc.perform(post("/register")
                        .contentType(MediaType.APPLICATION_JSON)
                        .content(objectMapper.writeValueAsString(request)))
                .andExpect(status().isOk())
                .andExpect(jsonPath("$.code").value(0))
                .andExpect(jsonPath("$.message").value("SUCCESS"));
    }

    @Test
    @DisplayName("登录接口 - 参数校验失败")
    void testLoginValidationFail() throws Exception {
        LoginRequest request = new LoginRequest();
        request.setPhone("123"); // 无效手机号
        request.setPassword("123"); // 密码太短

        mockMvc.perform(post("/login")
                        .contentType(MediaType.APPLICATION_JSON)
                        .content(objectMapper.writeValueAsString(request)))
                .andExpect(status().isBadRequest());
    }
}
```

## 📊 第五步：配置测试覆盖率插件

在父POM的 `<build><plugins>` 中添加:

```xml
<plugin>
    <groupId>org.jacoco</groupId>
    <artifactId>jacoco-maven-plugin</artifactId>
    <version>0.8.11</version>
    <executions>
        <execution>
            <goals>
                <goal>prepare-agent</goal>
            </goals>
        </execution>
        <execution>
            <id>report</id>
            <phase>test</phase>
            <goals>
                <goal>report</goal>
            </goals>
        </execution>
        <execution>
            <id>jacoco-check</id>
            <goals>
                <goal>check</goal>
            </goals>
            <configuration>
                <rules>
                    <rule>
                        <element>PACKAGE</element>
                        <limits>
                            <limit>
                                <counter>LINE</counter>
                                <value>COVEREDRATIO</value>
                                <minimum>0.70</minimum>
                            </limit>
                        </limits>
                    </rule>
                </rules>
            </configuration>
        </execution>
    </executions>
</plugin>
```

## 💡 测试最佳实践

### 1. 测试命名规范
```java
@Test
@DisplayName("方法名 - 测试场景 - 预期结果")
void test方法名_场景_预期结果() {
    // 测试代码
}

// 示例:
@DisplayName("注册 - 手机号已存在 - 抛出异常")
void testRegister_PhoneExists_ThrowsException() { }
```

### 2. AAA模式 (Arrange-Act-Assert)
```java
@Test
void testExample() {
    // Arrange - 准备测试数据
    User user = new User();
    
    // Act - 执行被测试的方法
    String result = userService.doSomething(user);
    
    // Assert - 验证结果
    assertEquals("expected", result);
}
```

### 3. 使用@BeforeEach准备通用数据
```java
@BeforeEach
void setUp() {
    // 准备每个测试都需要的数据
    mockUser = User.builder()
            .id(1L)
            .phone("13800138000")
            .build();
}
```

### 4. 验证Mock调用
```java
// 验证方法被调用了1次
verify(userMapper, times(1)).selectById(eq(1L));

// 验证方法从未被调用
verify(userMapper, never()).deleteById(any());

// 验证方法至少被调用1次
verify(userMapper, atLeastOnce()).selectById(any());
```

### 5. 测试异常情况
```java
@Test
void testThrowsException() {
    // 断言会抛出指定异常
    BusinessException exception = assertThrows(
        BusinessException.class,
        () -> userService.doSomething()
    );
    
    // 验证异常信息
    assertEquals(2001, exception.getCode());
    assertTrue(exception.getMessage().contains("用户"));
}
```

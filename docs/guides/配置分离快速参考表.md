# 📊 配置分离快速参考表

## 🎯 核心原则速查

| 配置类别 | 存放位置 | 原因 |
|---------|---------|------|
| 服务名称 | ✅ 本地 | 启动必需 |
| Nacos地址 | ✅ 本地 | 连接配置中心必需 |
| 数据库配置 | ❌ Nacos | 环境差异 + 敏感信息 |
| 业务参数 | ❌ Nacos | 需要动态调整 |
| JWT密钥 | ❌ Nacos（加密） | 敏感信息 |
| 服务端口 | ❌ Nacos | 环境差异 |
| 日志配置 | ❌ Nacos | 需要动态调整 |
| MinIO配置 | ❌ Nacos（加密） | 敏感信息 |

## 📂 配置文件清单

### 本地配置文件（application.yml）

```yaml
# ✅ 所有服务统一模板（仅15行左右）
spring:
  application:
    name: camera-rental-xxx-service  # 唯一不同的地方
  cloud:
    nacos:
      config:
        server-addr: ${NACOS_ADDR:localhost:8848}
        namespace: ${NACOS_NAMESPACE:public}
        group: ${CONFIG_GROUP:DEFAULT_GROUP}
        file-extension: yaml
        shared-configs:
          - data-id: common-config.yaml
            group: SHARED_GROUP
            refresh: true
          - data-id: datasource-config.yaml
            group: SHARED_GROUP
            refresh: true
      discovery:
        server-addr: ${NACOS_ADDR:localhost:8848}
        namespace: ${NACOS_NAMESPACE:public}
```

### Nacos配置文件清单

| 配置文件 | 类型 | 适用服务 | 说明 |
|---------|------|---------|------|
| `common-config.yaml` | 共享 | 全部 | 通用配置 |
| `datasource-config.yaml` | 共享 | User/Device/Order/Coupon | 数据库配置 |
| `minio-config.yaml` | 共享 | Device | MinIO配置 |
| `redis-config.yaml` | 共享 | 需要时 | Redis配置（预留） |
| `seata-config.yaml` | 共享 | Order | Seata配置（预留） |
| `cipher-config.yaml` | 加密 | 全部 | 敏感信息 |
| `camera-rental-gateway.yaml` | 独立 | Gateway | Gateway配置 |
| `camera-rental-user-service.yaml` | 独立 | User | User服务配置 |
| `camera-rental-device-service.yaml` | 独立 | Device | Device服务配置 |
| `camera-rental-order-service.yaml` | 独立 | Order | Order服务配置 |
| `camera-rental-coupon-service.yaml` | 独立 | Coupon | Coupon服务配置 |

## 🔐 敏感配置加密清单

### 必须加密的配置项

| 配置项 | 在哪个文件 | 加密形式 |
|--------|-----------|---------|
| 数据库密码 | `datasource-config.yaml` | `${DATASOURCE_PASSWORD}` → `cipher-config.yaml` |
| 数据库用户名 | `datasource-config.yaml` | `${DATASOURCE_USERNAME}` → `cipher-config.yaml` |
| JWT密钥 | `gateway.yaml` / `user-service.yaml` | `${JWT_SECRET}` → `cipher-config.yaml` |
| MinIO AccessKey | `minio-config.yaml` | `${MINIO_ACCESS_KEY}` → `cipher-config.yaml` |
| MinIO SecretKey | `minio-config.yaml` | `${MINIO_SECRET_KEY}` → `cipher-config.yaml` |
| Redis密码 | `redis-config.yaml` | `${REDIS_PASSWORD}` → `cipher-config.yaml` |
| Druid监控密码 | `datasource-config.yaml` | `${DRUID_PASSWORD}` → `cipher-config.yaml` |

### 加密配置示例

```yaml
# cipher-config.yaml（在Nacos中创建）
DATASOURCE_PASSWORD: ENC(aBcDeFgHiJkLmN...)  # 加密后的密码
JWT_SECRET: ENC(xYzAbCdEfGhIjK...)  # 加密后的JWT密钥
MINIO_SECRET_KEY: ENC(qWeRtYuIoPaSdF...)  # 加密后的MinIO密钥
```

## 🌍 环境配置对照表

### Nacos命名空间配置

| 环境 | Namespace ID | 配置特点 |
|------|-------------|---------|
| 开发环境 | `dev` | 本地数据库、宽松限流 |
| 测试环境 | `test` | 测试数据库、模拟数据 |
| 预发环境 | `staging` | 生产数据库副本、严格限流 |
| 生产环境 | `prod` | 生产数据库、最严格配置 |

### 启动命令对照

```bash
# 开发环境
java -jar app.jar \
  --spring.profiles.active=dev \
  --spring.cloud.nacos.config.namespace=dev

# 生产环境
java -jar app.jar \
  --spring.profiles.active=prod \
  --spring.cloud.nacos.config.namespace=prod \
  --jasypt.encryptor.password=${JASYPT_KEY}
```

## 🚨 常见问题速查

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 服务启动失败：连接不到Nacos | Nacos地址错误 | 检查本地配置中的 `nacos.server-addr` |
| 配置加载失败 | 配置文件名不匹配 | 确保 `spring.application.name` 与Nacos配置文件名一致 |
| 敏感配置解密失败 | 加密密钥错误 | 检查启动参数 `jasypt.encryptor.password` |
| 配置不生效 | 未引用共享配置 | 检查 `shared-configs` 配置是否正确 |
| 多环境配置混乱 | 命名空间配置错误 | 确保 `namespace` 参数正确 |

## 🎯 配置优先级

```
高优先级
   ↓
系统环境变量
   ↓
启动参数
   ↓
Nacos加密配置（cipher-config.yaml）
   ↓
Nacos服务配置（{service-name}.yaml）
   ↓
Nacos共享配置（shared-configs）
   ↓
本地配置（application.yml）
   ↓
低优先级
```

# Camera Rental 项目简历说明（可直接用于简历/面试）

## 1. 项目概述

- **项目名称**：Camera Rental / LensGo（相机租赁平台）
- **项目定位**：面向相机租赁场景的前后端分离微服务系统，覆盖"设备发布-下单-履约-归还-评价"完整闭环，内置 IM 实时聊天、纠纷处理与管理后台。
- **架构形态**：Spring Cloud Alibaba 微服务架构（Gateway + User/Device/Order/Coupon 四个业务服务 + Common 公共模块）。
- **核心价值**：提升租赁流程在线化与可追踪性，支持用户端与管理后台协同运营。

## 2. 业务流程（可在面试中重点讲）

- 订单主流程：`待支付 -> 已支付 -> 待发货 -> 待归还 -> 已归还/逾期 -> 完成`
- 异常分支：支持未支付取消、超时自动取消（30 分钟）、逾期识别与状态流转。
- 关键业务能力：优惠券领取与核销、设备收藏、订单评价、站内消息通知、IM 实时聊天、订单纠纷处理。
- 消息通信：RabbitMQ Outbox 模式实现订单事件的可靠异步分发，支持用户通知、设备状态同步、优惠券状态同步。

## 3. 技术栈

- **后端**：Java 17、Spring Boot 3.2.x、Spring Cloud Alibaba、Spring Cloud Gateway、OpenFeign、MyBatis-Plus
- **中间件**：Nacos、Redis、MySQL、MinIO、RabbitMQ、Sentinel、Druid
- **接口文档**：OpenAPI 3 + Knife4j（网关聚合）
- **前端**：Vue 3、Vite、Pinia、Vue Router、Element Plus、Axios、ECharts
- **工程化**：Maven 多模块、Docker Compose、统一异常与统一返回体、配置中心分层管理

## 4. 我的核心贡献（模板，按你的真实职责替换）

### 4.1 后端架构与业务实现

- 设计并实现微服务拆分：网关层统一鉴权和路由，业务服务解耦。
- 负责订单服务核心流程实现，包含创建、支付、发货、归还、确认完结等完整状态机逻辑。
- 实现 Outbox 模式（`mq_outbox` + `OutboxPublishJob`），保证数据库操作与消息发送的最终一致性。
- 落地 OpenFeign 服务调用与 fallback 兜底，降低跨服务调用失败对主链路的影响。
- 建立统一错误码、全局异常处理、统一响应结构，提升接口可维护性与前后端协作效率。

### 4.2 性能与稳定性优化

- 引入 Redis 缓存与多级 TTL 策略，降低热点查询对数据库压力。
- 对优惠券领取场景采用 Redis 原子操作，避免并发超发问题。
- 实现重复提交拦截（注解 + AOP + Redis 锁），降低重复请求导致的数据脏写。
- 实现订单超时自动取消任务，避免长期占用库存与脏状态累积。
- 优惠券过期自动状态更新（`CouponExpireJob`），保障数据一致性。

### 4.3 安全与权限治理

- 在网关实现 JWT 双 Token 鉴权过滤（AccessToken + RefreshToken），统一解析用户身份并向下游透传上下文。
- 设计白名单机制，区分公开接口与受保护接口，减少误拦截风险。
- 在业务层增加管理员权限校验（`@AdminOnly` 注解 + `AdminInterceptor`），覆盖后台敏感操作。
- 将敏感配置（账号、密钥）与普通配置分离，支持 Nacos 统一配置管理。

### 4.4 前端与体验改进

- 实现用户端与管理后台双端路由体系，支持角色化访问控制。
- 完成 Axios 请求封装（鉴权、401 静默刷新、失败重放队列），提升登录态稳定性。
- 集成 ECharts 实现管理后台订单趋势图等数据可视化。
- 实现 IM 实时聊天系统（WebSocket + STOMP），支持租用者与出租者在线沟通。
- 统一业务状态枚举与格式化工具，降低页面重复逻辑，提升开发效率。

## 5. 关键技术亮点（面试可展开）

- **统一鉴权链路**：Gateway 处理 JWT 双 Token，业务服务聚焦业务本身，职责边界清晰。
- **Outbox 模式**：数据库事务与消息发送解耦，通过定时任务重试保障消息可靠投递，避免分布式事务。
- **配置中心分层**：公共配置与服务私有配置拆分，支持环境切换与运维效率提升。
- **文档聚合治理**：通过网关聚合 OpenAPI/Knife4j，减少多服务调试切换成本。
- **并发安全设计**：优惠券 Redis 原子库存 + 防重提交拦截，保障高并发下数据一致性。
- **实时通信**：WebSocket + STOMP 协议实现 IM 聊天，Gateway 层统一 WebSocket 路由。
- **可观测性基础**：集成 Druid SQL 监控、Sentinel 流控、`@OperationLog` 操作日志，为监控扩展预留空间。
